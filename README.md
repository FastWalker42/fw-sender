# FW Sender — Telegram Broadcast Bot

Автоматизация рассылок в Telegram-каналы на **Bun** + **TypeScript** + **Grammy** + **Bun SQLite**.

## Архитектура

```
Каналы ← m2m → Кампании
                  ├── Автоспам (рандомный пост без повторов подряд)
                  └── План постов (конкретные дата/время, АВТО, растяжка по дням)
```

### Сущности

- **Каналы** — список управляемых Telegram-каналов
- **Кампании** — центральная сущность:
  - Привязка каналов (many-to-many)
  - **Автоспам** — набор постов, бот выбирает случайный без повторов подряд
  - **План постов** — посты с датой/временем, кнопка АВТО (дефолт-время кампании), растяжка по дням
  - Расписание (простое время / подробное через tgwidget)
  - Дефолт-время для плана постов
  - Уведомления при 3/2/1 оставшихся постах в плане

### Хранение постов

Все посты хранятся как `chatId:messageId` — бот отправляет через `copyMessage`.

### Дата и время

Задание даты/времени реализовано через `@grammyjs/conversations`:
- **WebApp кнопка** — tgwidget виджет (liquid glass стиль)
- **Ручной ввод** — формат из SDK (`widget.pattern`)
- **Кнопка «Отменить»** — выход из диалога

## Технологии

- [Bun](https://bun.sh/) — runtime
- [Grammy](https://grammy.dev/) — Telegram Bot Framework
- [@grammyjs/conversations](https://grammy.dev/plugins/conversations) — диалоги
- [Bun SQLite](https://bun.sh/docs/api/sqlite) — встроенная БД
- [tgwidget](https://github.com/tgwidget/tgwidget.github.io) — виджеты выбора даты/времени (liquid glass стиль)

## Установка

```bash
# Клонировать
git clone https://github.com/FastWalker42/fw-sender.git
cd fw-sender

# Установить зависимости
bun install

# Настроить окружение
cp .env.example .env
# Заполнить BOT_TOKEN, ADMIN_IDS, BOT_USERNAME в .env

# Запустить
bun run src/index.ts
```

## Inline-меню

### Главное меню
- 📢 **Каналы** — список, добавление (ID / @username / пересланное сообщение)
- 🔗 **Кампании** — CRUD кампаний

### Кампания
- 📨 **Автоспам** — посты для автоматической рассылки (рандом без повторов)
- 📥 **План постов** — посты с конкретными датами/временем
- 📢 **Каналы** — привязка/отвязка каналов
- 🕓 **Расписание** — conversation с WebApp виджетом или ручным вводом
- 🕓 **Дефолт-время** — conversation с WebApp виджетом или ручным вводом
- 🔼/🔽 **Старт/Стоп** — активация кампании

### План постов
- Каждому посту можно задать дату и время (через conversation с tgwidget WebApp)
- 🤖 **АВТО** — устанавливает дефолт-время кампании
- 📅 **Растянуть по дням** — равномерно распределить посты на N дней

## Названия постов

В списках постов отображается:
- Начало текста / caption
- `КРУЖОЧЕК #N` — для video note
- `СТИКЕР #N` — для стикеров
- `ГОЛОСОВОЕ #N` — для голосовых
- `ФОТО #N`, `ВИДЕО #N`, `GIF #N`, `АУДИО #N`, `ДОКУМЕНТ #N`, `КОНТАКТ #N`, `ЛОКАЦИЯ #N`
